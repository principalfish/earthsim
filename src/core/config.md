# Model settings

Every setting the climate models run on, with its value and unit, what it controls, what raising and lowering it do, where its value comes from and whether it was tuned. Written by `npm run docs:config` from [`config.ts`](config.ts), which is where a setting is changed; do not edit this page by hand.

Raising it and Lowering it say what moving a setting away from the value shown does, everything else left as it is. K is a kelvin, a step of 1 °C.

## Temperature

The settings of the temperature model, read from `TEMPERATURE_CONFIG` into `TEMPERATURE_MODEL`. How the model works is in [Temperature](../../docs/temperature.md).

22 settings: 14 physical and 8 numerical, 4 of them tuned against the observed Earth. A run may override these. Beyond them the code reads 5 fixed choices directly, which a run cannot override.

### How heat moves and is stored

### The climate loop

|-|-|-|-|-|-|-|
| `climateToleranceC` | 0.1 °C | How small the root-mean-square change a pass of the climate loop makes to the monthly temperature, over the whole globe and the year, must be for the climate to count as settled. | The loop stops sooner, on a climate a little less settled. | More passes, to a climate settled more finely; below about 0.05 the temperature's own tolerance sets the limit. | Chosen: below what a map of the temperature shows. ## Winds

36 settings, 11 of them tuned against the observed Earth. A run may override these. Beyond them the code reads 4 fixed choices directly, which a run cannot override.

### How wide the circulation cells are
