# Planning record

This branch holds the planning history for this repo: one folder per issue
under `issues/` (decisions, plan, reviews), saved investigations, reviews
of other people's work, and a log of quick builds. It shares no history with
the code branches.

It is maintained by the Claude Code skills in `~/.claude` (`/planner`,
`/builder`, `/review`, `/publish`, `/quick-build`, `/issues`) through
`~/.claude/lib/planner.py`. `INDEX.md` is regenerated on every save; `log.md`
and `quick-builds.md` are append-only.
